# TimIQ Web

Next.js frontend for TimIQ.

## Local setup

Run all npm commands from **this directory** (`apps/web`). Use the lockfile here (`package-lock.json`). TimIQ is not an npm workspace; do **not** install from the repository root.

```bash
cd apps/web
npm ci
npm run dev
```

Other useful commands (still from `apps/web`):

```bash
npm run typecheck
npm run build
npm run start
```
